---
title: Locations
audience: administrators
---

**Administration → Organization → Locations** lists the places of your organization: sites, buildings, floors and rooms. Asset managers, team leads and administrators manage them. Other parts of the application offer them in their forms, for example to record where an asset is.

Locations are nested. Create the site first, then a building **inside** it, then a room inside the building. The list shows each one with its full name, for example *Bucharest HQ › Building A › Server room*.

- Two locations in the same place cannot have the same name, but two buildings can each have a "Server room".
- A location cannot be moved inside itself or inside one of its own sub-locations.
- A location that still contains others cannot be deleted. Mark it **inactive** instead: it stays on existing records but is no longer offered.

Every change is recorded in the audit trail.
