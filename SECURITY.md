# Security policy

## Reporting a vulnerability

**Do not open a public issue.** Report it privately through GitHub: on the repository's [Security tab](https://github.com/cosmin-andrei-ro/ICT-Management-Toolkit/security), choose **Report a vulnerability**. Only you and the maintainers see the report.

Please include:

- what an attacker can do, and what they need first (an account, a role, network access);
- the steps to reproduce it, and the version or commit;
- any idea you have for a fix.

Use made-up data in your report, and do not test on systems you do not own or have no permission to test.

## What happens next

This project is maintained by volunteers, so these are aims and not guarantees:

1. We confirm that we received the report.
2. We check it and tell you whether we can reproduce it.
3. We fix it, publish the fix, and publish an advisory.

Please keep the details private until the fix is out. We credit you in the advisory, unless you prefer not to be named.

## Supported versions

There are no numbered releases yet. Security fixes go to the `main` branch only, so keep your installation up to date with it.
