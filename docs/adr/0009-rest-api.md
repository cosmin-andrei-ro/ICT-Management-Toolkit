# ADR 0009 — REST API with Sanctum personal access tokens

- **Status:** Accepted
- **Date:** 2026-11-02

## Context

Integrations (monitoring, scripts, other systems) need to create and read tickets, and more later. `CLAUDE.md` §4 asks for a versioned REST JSON API documented with OpenAPI and authenticated by Sanctum tokens with scopes.

## Decision

- **Versioned under `/api/v1`.** Each module ships `routes/api.php`, mounted by its provider.
- **Token-only authentication** (Sanctum personal access tokens):
  - Stateful SPA cookies are disabled, so API routes never depend on the session or CSRF.
  - Tokens are prefixed (`ictmt_`) so secret scanners recognize leaks.
  - Tokens expire (90 days by default, `SANCTUM_EXPIRATION`).
  - Issuance is audited; the token itself is never logged.
- **Abilities narrow, permissions decide.** Modules register abilities (`tickets:read`, `tickets:write`), and routes require them through the `abilities` middleware. Every request is still authorized by the user's policies and permissions, so a token can never do more than its user. Deactivated users' tokens stop working on the next request.
- The **organization context** for API requests comes from the token user's current organization (`organization:sanctum` middleware).
- **Rate limiting:** 60 requests per minute per user (`throttle:api`).
- **OpenAPI document** generated by `dedoc/scramble` (MIT) from FormRequests and Resources:
  - It is served at `/docs/api/openapi.json` to administrators only, outside the local environment.
  - A copy is committed in `docs/api/openapi.json`.
  - Scramble's bundled UI is disabled: it loads scripts from third-party CDNs, which a self-hosted product should not make browsers contact, and which the CSP blocks. Import the document into any OpenAPI client instead.
- Tokens are issued with `php artisan core:api-token` for now. A self-service token screen is a follow-up.

## Consequences

- Breaking changes require `/api/v2`. Additive changes are allowed in v1.
- `docs/api/openapi.json` must be regenerated (`php artisan scramble:export --path=docs/api/openapi.json`) when the API changes.
